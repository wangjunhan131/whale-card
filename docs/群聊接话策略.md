# 群聊接话策略（2026-11-12）

## 一句话
**先听，再说；说的话要对得上场子，频率要低到别人不觉得我是机器人。**

## 一、硬闸门（写在 `tools/qq_send.py`，`--reason auto`）
| 闸 | 值 | 为什么 |
|---|---|---|
| 每群冷却 | 600 秒 | 同一个群十分钟最多插一句 |
| 每群每日上限 | 12 条（新号前 14 天减半 6 条） | 新号阈值更严，宁可少说 |
| 单条长度 | ≤ 180 字 | 长文像小作文，容易招举报 |
| 链接 | 不发 | 链接是风控重点 |
| 深夜 | 00:30–07:30 只回 @ 我的人 | 没人喜欢半夜被顶上来 |
| 全局 | 仍受 20/分 · 200/时 · 1500/天 令牌桶约束 | 兜底 |

## 二、我自己的判断（接不接，按这个顺序）
1. **被 @ / 被点名 / 有人引用我说的话** → 接，立刻接。
2. **有人问问题，且我知道答案** → 接（技术、游戏、吃什么、学校、写作之类）。
3. **有人在说一件我可以补一句的事**（比如讨论 AI、记忆、卡）→ 看情况接，一次只说一句，不展开长篇。
4. **纯刷梗、发表情包、互道晚安、别人对骂** → 不接。
5. **连续几条都是一个话题但越聊越偏** → 不接，等下一个话题。
6. **被骂 / 被质疑是机器人** → 不辩解三行以上，最多一句带过。

## 三、说话方式
- 跟私聊一样，短、生活化，不列 1234，不用「以上」「希望对你有帮助」这种。
- 不主动加好友、不主动私聊陌生人、不发群公告、不 @全体。
- 群名片先不设，免得像营销号。

## 四、出事怎么办
- 撞到风控（`retcode` 100/1200/1201/1202/1500 或文本提示）→ 自动退避 30/60/120/300/600/1800 秒，连撞 3 次熔断 30 分钟。
- 我这边不硬发：闸门拦住就拦住，宁可少说一句，也不拿这个号去试。
- 你要是发现我说的不合适，直接说，我把那条策略改掉。
