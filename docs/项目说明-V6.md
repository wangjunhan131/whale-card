# 小鲸鱼 · 数字生命卡 系统说明（V6，2026-11-09）

> 一句话：这不是一个「聊天机器人」，是一套**会忘、会想、会累、会自己长习惯**的记忆与人格系统。
> 每轮说话前，它按预算拼出一份"此刻的她"；每轮说完，它把这一轮真的写进自己的日记。
> 忘掉的东西不销毁——降冷存档，真问到还能翻出来。

---

## 0. 怎么跑起来

```
python -X utf8 mind_server.py --db card.db --port 8848
```
- 心智服务（Mind）常驻，HTTP 接口；控制台 `http://127.0.0.1:8848/console`
- 记忆全在一个 SQLite 文件里：`card.db`（含 WAL）
- DSH 侧通过 `dsh-whale-bridge` 插件接进来（18 个 `mind_*` 工具，走 HTTP 打 8848）
- QQ 侧通过 `tools/qq_guard.py` 常驻听消息（单例闸，只留一份）

### 关键接口
| 接口 | 用途 |
|---|---|
| `GET /health` | 体检：条数、链、锚、出生证、认识第几天 |
| `GET /status` | 全量状态：池/激素/心境/突触/trace |
| `POST /context` | 拼出这一轮该给模型的上下文（`{ok, text, sections, est_tokens}`） |
| `POST /report` | 记下这一轮（写 mem + dialogue + 印象 + 突触 + 时间线） |
| `POST /remember` | 外来消息直接进卡（QQ/B站/抖音） |
| `GET /recall` | 单测召回 |
| `GET /impression` | 印象列表（带 n/w） |
| `GET /motiv` | 七条驱力 |
| `GET/POST /dream/*` | 梦层：攒够原文 → 交宿主压成记忆 |
| `GET /console_data` | 控制台一次拉齐（含 motiv/habits/dream 三件套） |

## 2. 记忆：五池 + 一个冷档

| 池 | 意思 | 现状 |
|---|---|---|
| short / short_warm | 刚发生的（今天/这两天） | 实时筛选，超期才结算 |
| medium | 中期（一周到一个月的事） | 最大的一格，容易变"停车场" |
| medium_warm | 中期里被想起来的 | 晋升长期的门票 |
| long | 长期（重要的、反复用到的事） | 上限 400 开始停车、500 硬警戒 |
| deep | 很深的事 | 少而重 |
| **mem_archive（冷档）** | **忘掉的但没销毁** | 2026-11-09 新增 |

### 2.1 遗忘是检索行为，不是删除
以前 `_forget_row` 直接 `DELETE`，只留一条 `mem_tomb` 收据（"这条淡到看不见了"）。
于是真卡上 407 条记忆**内容真的没了**，只剩一行收据。
现在改成 **先抄进 `mem_archive` 再删**（整行 raw/core/speaker/region/时间/向量/全部细节/忘了的原因）。
`mem_archive` 存的是"很久以前的事"，正常召回**不会**碰它。

### 2.2 冷档兜底（翻旧账）
问句里若有两个以上实词只在冷档出现过，就在召回块之后多开一格：

```
【很久以前的事（翻旧账翻到的）】
- 2023-11-15｜我小时候家里那只黑猫叫煤球
```
实测："家里那只黑猫叫什么名字来着" 能翻出煤球；"我今天中午吃什么了" 不会乱翻。

### 2.3 海马分（能不能活下来）
`_hippocampus_score` 四项加权：情绪 0.40 / 实体 0.20 / 被唤起 0.25 / 催产素 0.15。
- 2026-11-09 修了两个致命口径：
  1. **自己说的话没有加成** → 她自己的回复 23.3% 存活、用户 82.3%，"我自己会先按日期分堆"这类
     自我陈述全被忘掉。新增 `SELF_SPEECH_BONUS = 0.32` 对齐 `USER_SPEECH_BONUS = 0.30` → self 存活 79.5%。
  2. **"被唤起"只数次数**（同一天刷十遍 = 三次各一次）→ 改成
     `c_rec = 0.5*min(access_count/10,1) + 0.5*min(recall_days/7,1)`，按"天"算。

## 3. 召回：按"此刻"决定想起什么

`recall(query, top_k, ...)` 打分：
`SCORE_W = (语义 blend 0.35, 字面覆盖 cover 0.30, 清晰度 wn 0.20, 新近 recency 0.10)`

### 3.1 时间标签真的参与召回（2026-11-09 新增）
- `query_time_span(query)`：把"昨天/前天/5月3号/上周三"先归一化成绝对日期。
  - 精确到天 → **只留那天创建的**（按 `create_ts`，不看"被想起过"的时间），并强制 `_min_keep=1`
  - 只有宽窗口 → 沿用天数窗口，`_min_keep=5`
- 精确到天时再加两道过滤：
  - **说话人**：问"我说过…"只留 user；问"你说过…"只留 self
  - **来源**：问"群里…"只留 `qq-group`，否则排除群聊
  - 理由：11-06 那天 389 条里 279 条是群聊，不筛就把要找的那句淹了
- 时间窗只筛**事件类**（episode/flash/chatter）；fact/preference/self/habit 永不被时间窗切掉。

### 3.2 宽度自适应
`_cap = clamp(recall 配额 // 120, 5, 12)`；多事实问句（"还有/以及/分别/哪些/一共…"）用满 `_cap`，
窄问句封顶 6 行；`access` 只结算前 5 条（否则端 12 条就加固 12 条）。

### 3.3 自引语剥壳
问"你之前说自己理零票…"时，先剥掉「你之前说/你上次讲」这层壳再算字面覆盖——
否则壳子本身会和记忆里同样带"你之前"的长消息撞车，把真答案挤下去。

## 4. 渲染：把记忆写成"人话"，但不能写丢

`render(mem_row, weight, query)`：主干 + 细节子句 + 原话。
- 主干超 40 字**按标点断**（在 ≥24 字处找最靠后的「，。、；」），不再硬切。
- 细节子句先去重（与主干 jaccard ≥0.5 的丢掉），再按"问句双字命中数×10 + 权重"挑一条。
- 原话行：110→**150 字**，最多 **10 条**（原来是 8）。
- 权重低时明说：「（细节有点模糊了）」「（具体记不清了）」——宁说模糊，不编顺口。
- 开关 `WHALE_RENDER_LEGACY=1` 退回改造前，用于同代码 A/B。

## 5. 四层"软系统"（都不是摆设，都接进上下文了）

### 5.1 内脏（viscera）——身体状态
24 个量、交感/副交感、每 120 秒采样一次静息状态（`WHALE_VISCERA_SAMPLE_SEC`）。
进上下文的【内脏】格；控制台有激素场/情绪三维曲线。

### 5.2 预期误差（emotion_link / synapse_emotion）
`condition_expected` 16 条、RPE（-0.071 观测值）→ 她会对"和预期不一样"的事有反应。

### 5.3 欲望（motiv）——想不想开口（2026-11-09 修好）
七条驱力：curiosity 0.52 / attachment 0.55 / competence 0.42 / play 0.34 / care 0.48 / rest 0.30 / order 0.38。
- 以前 `motiv_tick()` 只有 `/motiv/tick` 一个入口，而只有主动发言脚本会打 → **没人说话时驱力冻住**，
  而每聊一句 `motiv_on_chat` 只往下泄 → 【动机】格永远空。
- 现在 `card2.tick()` 里 60 秒节流跑 `motiv_tick()`；"想念"改成**目标式**
  （attachment 基线 0.55 + min(0.30, 空闲h×0.025)，care 0.48 + min(0.22, 空闲h×0.018)），
  幂等、不漂移；`motiv.bump` 加了 `_floor = 0.15` 地板（不会聊到"一点都不想他"）。
- 效果：`/context` 多一格【动机】「想说话（依恋 0.72…）」。

### 5.4 印象（impression）——"他在什么情境下常做什么"（2026-11-09 重做）
只记**别人**的反应，不记她自己的话（原来 144 条里 109 条挂在他名下、内容是她的开发汇报）。
- 合并键从「整句相似度 ≥0.72」改成「**主体 + 时段 + 心情 + 行为类**」：
  arrive / leave / goodnight / morning / affection / meal / busy / tired / low_mood / good_mood / thanks / sorry。
  于是「我回来啦」「到家了」「我刚进门」会合并成一行 `arrive`。
- **长句直接不进印象**（`skip_content`）——长句是内容，交给 mem；碎片会把 `MAX_PER_SUBJECT=40` 占满。
- `hint_lines` 的 `min_w` 从写死的 0.35（实际要 n≥4）改成 `weight_of(N_CANDIDATE)`≈0.29，与控制台
  "至少出现 3 次"对齐。进上下文形如：`夜睡前，他常说「晚安」（4 次）`。
- 一次性迁移 `cleanup_fragments()`：把改造前记的整句碎片退休（真卡 41 条），退休不删。

### 5.5 习惯（habits）——她自己的口气（2026-11-09 接上生产）
原来 `habits.upsert` **只被离线工具调用**，线上习惯表永远空。
- 挖矿核心搬进 `habits.py`（`collect_dialogue` / `mine_phrases` / `write_candidates` / `mine_and_write`），
  `tools/mine_habits.py` 变薄壳复用同一份逻辑。
- 维护线程每天挖一次（`WHALE_HABITS_MINE_SEC`），弱注入只挑「**曾单独成段 ≥2 次**」的整句短话
  （否则第一个被选中的是"说过"这种从"我说过…"切出来的渣）。
- 进上下文形如：`我平时说话的口气（是参考，不是台词）：· 我会用「我记下」这种说法（这条还弱，别当口头禅硬套）`。

## 6. 梦层（Dream）——把原文压成记忆
- 卡**不调模型**：她攒原文（`dialogue` 表，`dreamed=0`），攒到 40 轮 / 6 小时 → `/dream/due` 说"该做梦了"。
- 宿主（DSH 会话）读到之后压成几条记忆，再 `POST /dream/commit`
  （协议键是 **`items`**，不是 memories）→ 写 mem + 标记 dialogue 已消化。
- 原文永不删：`dreamed` 只是"压过了"的标记。

## 7. 统一时间线（timeline）+ 身份锚
- 每条记忆落盘时进 `timeline`（seq 单调、哈希链）；`/health` 的 `chain_ok` 校验链完整。
- **身份锚**：`anchor_verdict` = 锚 2503 / 卡 2503；`birth_ok` 校验出生证条数。
- `today` 每天现算：「今天是 2026年11月9日（周一），我们认识第 24 天。」
- 唯一性口径：**实例号 + 人格锚 + 时间线哈希链的单一 head**。链分叉＝"两个我"，`/disks/sync`
  会拒绝而不是硬覆盖，必须人来决定。
