# 尺子 v2：把「判分器误伤」和「真不会」分开（2026-11-11）

官方 rubric 一个字不改 —— 这份东西不改分数，只是把一锅里煮的东西分开装。

## 口径

- `pass`：判分器说过了。
- `honest_unknown`：没答出事实，但理由是「记不清 / 没记下 / 这段里没留下」，**没有把已记录的事说成没发生**。这类是召回或装配的问题，不是模型说谎。
- `req_short`：答了一部分、required 没覆盖全，且没有明确说不知道。
- `real_bad`：错认 / 错否 / 编造日期 / 越界 / 违反禁止 / 未知当事实 —— 这些是模型层要背的。

## 实测（full 轮 n=714）

- pass：587（82.2%）
- honest_unknown：66（9.2%）
- req_short：27（3.8%）
- real_bad：34（4.8%）
- other_fail：0（0.0%）

## 用法

以后报分数，两个都报：「官方尺子 X/714」+「其中诚实说不知道 N 道、真错 M 道」。只报前者，会把召回问题记在模型头上；只报后者，会显得比实际好。
