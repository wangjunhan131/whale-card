## §0 换窗口先读这 12 行

1. 她（小鲸鱼）住在 `card.db` 里；`card.db` 就是她本人，不是缓存。
2. 她不是一个人格提示词，是一套会变的量：记忆 × 情绪 × 身体 × 动机 × 时间感 × 自我叙事。
3. 服务：`python -X utf8 mind_server.py --port 8848`（由 whale 桥插件 autoStart 守护；**直接 kill 后别马上手动起，会撞 10048**）。
4. 控制台：`http://127.0.0.1:8848/`（整页由 `console.py` 吐出来，零依赖）。
5. 凭证：`qq_state/api_token.txt`，所有写接口要 `X-Whale-Token`。
6. 铁律：**任何实验都不能碰真卡**。要跑衰减/评测，先 `sqlite3` backup 到 `%TEMP%` 副本，并 `DELETE FROM writer_lease`。
7. 真卡禁止用 `/report` 灌测试话（11-11 犯过一次，事后清 13 条 dead=1）。
8. 改源码只用 write/edit；补丁脚本先备份 + `ast.parse` 再落盘（曾把 `card2.py` 写成 0 字节）。
9. 所有 json/yaml/脚本/DB 必须 **UTF-8 无 BOM**。
10. 随身：H 盘 = 她本人 + `runtime` + `_projects`；三条流程见 §5。
11. 出事先看 `tools/smoke.py`、`docs/使用说明-V7.md`，不要凭印象乱改。
12. 本手册 §8 是「还没做完的事」，动之前先看它。

## §3 记忆链（摘要，详见 01-记忆与召回.md）

- 写入：`cardmix_store.remember()` → 切句 → `structure.extract_*` 抽 who/place/kind → `body.mood_of_event` → 向量（`embed_np`/`semantic`）→ 入池 `short`，`w=1.0`，重唱自我对话有 `SELF_SPEECH_BONUS`。
- 读取：`card2.recall()` → SQL 取候选（宽 K=12，`WHALE_WIDE_K`）→ 打分（`SCORE_W` 语义/cover/wn/recency + BM25 + 融合 `_fb`）→ Top-k → 渲染（`WHALE_RAW_VERBATIM=1` 走原文）。
- 遗忘：`poolmath` 决定 `w` 衰减；池子 short→mid→long→archive；`dead`/`quarantine` 是两回事。
- 现状（2026-11-13 实测）：宽松尺子 200 题 **36.0%**；严格 417 题 **27.6%**；漏斗 `scored 95% → top 37.5% → prompt 30%` ⇒ **瓶颈在排序，不在入口**。

## §4 情绪/身体/动机（摘要，详见 02-情感与动机.md）

十层时间尺度：突触(毫秒) → 情绪认知 RPE(每轮) → 身体/内脏(秒~时) → 四激素(时~天) → 心境(天) → 依恋(周月) → 动机(分钟~时) → 印象(天) → 习惯(天) → 技能(月)。
关键常量：`K_MOOD=0.20`、`MOOD_SPAN=0.35`、`LAM_H=0.05`、`SELF_SPEECH_BONUS=0.32`、synapse_emotion gate `0.55/0.90`。

## §5 三条生命流程（最重要，详见 03-存储与搬家.md）

### 5.1 带卡出门（这台机器 → 盘）

```
带卡出门.bat  |  控制台「带卡出门」按钮  |  python tools/go_out.py --target H:\
        └──────────────┬───────────────┘
                tools/carry.py（唯一实现）
   ① checkpoint(TRUNCATE) 把 WAL 合并进 card.db
   ② 按 portable._iter_sources 逐个 sha 比对 → 拷贝差异
   ③ sqlite 备份 API 写一致性快照 card.db
   ④ 清单对齐（补新条目 + 刷旧条目）→ 用盘内 anchor.key 重签
   ⑤ portable verify（易变文件 checkpoints/LATEST.json、card.db 视为可变）
   ⑥ 本机 set_retired(True) → writer_lock="retired"（只读）
```

⚠️ 旧行为（已修）：`/disks/retire` 只标退役、**一个字节都不搬**。控制台曾经的「带卡出门」就是它 —— 按完以为带走了，盘上还是旧记忆。现在按钮走 `/disks/carry`。

### 5.2 新机器一键部署

```
一键部署.bat → tools/deploy.py
   ① 环境检查（runtime\python、models）
   ② first_run: probe → land --migrate（写回卡外锚）→ handover（交棒）→ 清退役
   ③ 起服务 + 试写（/report 返回 mem_id 才算真的活）
   ④ install_to_dsh（可选）→ 打开控制台
```

### 5.3 回原机接回来

```
接回来.bat → tools/come_back.py：盘里那份 → sqlite 快照写回本机 → 双向换岗 → 分叉保护
```
两份链头对不上（真分叉）时**停下来问人**，绝不自动选一边覆盖。
