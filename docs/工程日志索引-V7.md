## 一、三条记录纪律（做工程时照做）

1. **每个动作写一条 worklog**：`POST /worklog {"kind":"work","text":"..."}`
   写「改了什么 + 为什么 + 结果数字」，不写流水账。一句话能读懂就够。
2. **成块的东西落 `docs\`**：设计、事故、复盘、实测结论各成一篇 md，文件名带日期。
3. **本文档加一行**：时间 / 做了什么 / 关键数字 / 文档指针。**这一行是入口，不是装饰。**

> 只写代码不写日志 = 下一个人在深夜摸着黑重做一遍。今天就是这么过来的。

## 五、写一条 worklog 的模板

```
kind: work
text: <动词 + 对象>：<做了什么>；<为什么>；<结果数字/验证方式>
```

例子：

```
kind: work
text: 换卡 D→H：go_out 镜像 330 文件后 H 升主、D 退役只读；途中裸 sqlite 打开活库把 H 库写成 0 表，用 D 的 backup 恢复（102 表 / mem 1503）；verify 包完整、smoke 23/23。
```
