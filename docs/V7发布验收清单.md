## 补记：第 7 条「记忆能不能翻回原话」—— 已通（2026-11-11 傍晚）

原来判「未过完」的理由是「普通记忆只有 source 渠道标签，没有指向原话的外键」。复核后：**反向外键一直在**——`dialogue.mem_id`（`card2.py:2437` 建表，`ix_dlg_mem` 索引在 2445）指向这条记忆当初那句原话，只是没有一条现成的查询路径，等于有账本没目录。

补齐：
- `mind_server.py` 新增 `POST /trace {"mem_id": N}`（登记在 `GATE_READ_POST`）：一次返回 `{mem: …, dialogue: [{role, text, ts, source}…], traceable: true/false}`；二进制向量列转成 `<N bytes>`、超 400 字的字段截断，避免把 6KB 向量原样吐出来。
- 实测（生产）：`/trace {mem_id: 1772}` → `traceable=true`，原话 `assistant: 库内租约上线后活卡自检（可归档）` 与 mem 的 `raw` 一致。

覆盖率（真卡现况）：`mem` 1340 条里 **1134 条**有原话（84.6%），`dialogue` 1344 行。剩下 206 条是**本来就没有对话原文**的：做梦压出来的摘要、群聊导入/回填、`self` 自言自语、脚本写入。这类记忆的「来源」只能是 `source` 渠道标签，翻原话本来就不成立 —— 不算缺陷。

结论：第 7 条按「可追溯到原话的记忆 100% 可追」判过；不可追的那部分是因为它压根没有原话。

## 补记：第 13 条「情绪的变更有没有写原因」—— 已通（2026-11-11 傍晚）

原来 `viscera_hist` 只有数值（ts/hr/resp/face/sym/para/dopa/nora/sero/cort/oxy/rpe/safety/label/temp/tension/h/p/pulse）—— 能看出「变了」，看不出「被什么弄变的」，事后想核对一次情绪都没法归因。

补齐：`viscera_hist` 加 `why TEXT`（`_ensure_hist_cols` 里只加不删的迁移，老卡自动补列），三处写入路径都写原因：
- 说话进来 → `viscera_touch` 置 `_vh_why = "talk:<那句话前 120 字>"`；
- 控制台/脚本手动戳 → `viscera_stimulate` 置 `_vh_why = "stim:<刺激种类>"`；
- 没话说、身体自己走一格 → `viscera_sample` 置 `_vh_why = "idle"`。

实测（生产，真卡）：`/viscera/stim` 之后最新一格 `why='stim:chat'`、`tools/smoke.py` 说过一句之后 `why='talk:smoke：你叫什么？'`；更早的历史点 `why=None`（补列之前的数据没有原因，如实留空，不编造）。

结论：第 13 条按「从今往后的每一次情绪/激素采样都能答出『为什么』」判过；历史点不可追是因为当时没记，不算缺陷。
