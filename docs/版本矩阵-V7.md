## 这套版本怎么用

1. 装完/升级完先跑 `python tools/smoke.py`（19 项，FAIL 0 / WARN 0 才算装好）。
2. 出问题第一句问「你哪个版本」—— 答案就是 `/version` 或这份表。
3. 桥插件看**生效的那份**（profile 下 node_modules），不是仓库里源码那份。
4. 卡比代码新 → 别用旧代码跑；卡比代码旧 → 启动自动补列，补之前别双开。
