## 3. 带卡出门（把活卡镜像到 H，并让本机退役）

```powershell
python -X utf8 tools\go_out.py --target H:\
```

它内部就是 `tools/carry.py` 的六步：

1. `checkpoint`：`PRAGMA wal_checkpoint(TRUNCATE)`
2. `sync_files`：按 `portable._iter_sources()` 的规范清单逐个比 sha，不同才拷
3. `snapshot_db`：用 `disks._snapshot_db` 写一致性快照（不是裸复制）
4. `refresh_and_sign`：对齐 `PORTABLE-MANIFEST.json` 后用**包内** `anchor.key` 显式 `seal.sign`
5. `verify`：调 `tools\portable.py verify`；`VOLATILE = {checkpoints/LATEST.json, card.db}` 允差
6. （可选）`--retire`：`discs.set_retired(..., True)` + `writer_lock="retired"`

当次结果：**330 个文件**（拷贝 6 / 已一致 324）、重签 333 条、
`head_seq 3878 / card_sha256_ok true / carried_anchor true / verdict 包完整`。

## 6. 事故：把 H 的 card.db 写成了空壳

**现象**

- 清理后 `GET /health` 返回 500：`OperationalError: no such table: mem`（`card2.py` 的 `stats()` 里 `SELECT … FROM mem`）。
- `H:\card.db` 仍是 36,737,024 字节、header 还是 `SQLite format 3`，但 `sqlite_master` 里**一张表都没有**。
- 同时我用 `sqlite3.connect(r'H:\card.db')` + `dst.backup(src)` 拍的快照是 **0 字节**。

**原因（教训）**

我在服务还在跑、库处于 WAL 模式的时候，用**裸 `sqlite3.connect` 读写模式**打开活库，
想「顺手」拍一张快照。这个动作不该对活卡做——正确姿势只有三条：

1. 服务 API（`/report`、`/snapshot` 之类）
2. `disks._snapshot_db(...)`（内部就是 backup API + 一致性处理）
3. `sqlite3.connect("file:…?mode=ro", uri=True)` **只读**

**恢复步骤（照抄可用）**

```powershell
# ① 停掉 H 的服务
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*mind_server*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

# ② 坏文件留档（别删，留着以后查）
Move-Item 'H:\card.db' 'H:\_corrupt-card-<ts>.db' -Force
Remove-Item 'H:\card.db-wal','H:\card.db-shm' -Force -ErrorAction SilentlyContinue

# ③ 用 D 的完好库（102 表 / mem 1503）恢复
python -X utf8 -c "import sqlite3; s=sqlite3.connect(r'D:\...\card.db'); d=sqlite3.connect(r'H:\card.db'); s.backup(d)"

# ④ 自检
python -X utf8 -c "import sqlite3; c=sqlite3.connect(r'H:\card.db'); print(c.execute('select count(*) from sqlite_master').fetchone(), c.execute('select count(*) from mem').fetchone())"
```

恢复后：**102 张表 / mem 1503** → 重起服务（`WHALE_DB=H:\card.db`）→ `/health` 正常、`/worklog` 写入 ok。

## 8. 这次学到的规矩（已经进记忆，写在这里防止丢）

1. **活库绝不裸连读写**：只走 API / `disks._snapshot_db` / `mode=ro`。
2. **停服务要用 `/shutdown`**，不要 `Stop-Process`（WAL 与半截写就是这么来的）。
3. **桥插件 `cardDir` 是隐藏的抢端口凶手**：换卡必须同步改它，否则起来的是旧卡。
4. **清单要按规范文件重建**：`carry.refresh_and_sign` 会沿目录走，容易把 `dsh-plugin/node_modules` 全扫进去。
5. **`_refresh_manifest_hash` 取钥会往上一级找**：改完清单必须用**包内** `anchor.key` 显式 `seal.sign`，否则签错。
6. **坏文件留档，不删**：`H:\_corrupt-card-20261113-2212.db` 就是这么留下来的。
7. **每做一步都要能验证**：`/health`、`verify`、`smoke.py`，三个都过了才算做完。
