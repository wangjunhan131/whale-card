# DSH 插件清单（随身包）

> 目的：换电脑时**不用再一个个去插件市场翻**。有包的已经打进随身盘，没包的在这张表里留了名字和链接。
> 打包位置：`H:\_projects\plugins\`（随身盘跟卡走）；还原脚本：`tools\install_plugins.py`，也可以双击 `H:\_projects\plugins\` 里解压后跑。
> 生成时间：2026-11-13。

## 一、包里有什么

| 位置 | 内容 | 体积 |
|---|---|---|
| `profile\` | 拉起插件需要的元数据：`package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`、`cordis.patch.yml`、`cordis.yml` | ~200 KB |
| `node_modules.tar.gz` | 已装好的全部依赖（12,427 个条目，含所有插件的依赖树） | 73.7 MB |
| `packages\` | 三个 `file:` 装的本地包：`dsh-freellmapi-0.7.18.tgz`、`dsh-startup-screen-1.1.0.tgz`、`dsh-memewiki-0.1.20\`，外加 `dsh-memewiki-data\memes.db`（梗库 16.3 MB，装的时候被 DSH 占着，单独拎出来了） | 33 MB |
| `wheels\` | Python 侧：`scrapling 0.5.1` 及依赖（curl_cffi / browserforge / tld / playwright / lxml …） | 30 MB |
| `PLUGINS.json` | 机器可读清单（名字、版本、来源、安装命令） | — |
| `PLUGINS.md` | 人看的表（本文件同源） | — |

## 二、还原到新电脑（三步）

```powershell
# 0) 新电脑先装好 DSH 本体（自带 @deepseek-ai/dsh-base 等核心 bundle）
# 1) 从随身盘跑还原脚本
cd H:\
python -X utf8 tools\install_plugins.py --dry     # 先看会做什么
python -X utf8 tools\install_plugins.py           # 真装：配置 → 备份旧文件 → 解压 node_modules → 放回本地包
# 2) 重开 DSH；要 scrapling 的话（会打印现成命令）：
pip install --no-index --find-links "H:\_projects\plugins\wheels" scrapling
```

脚本的原则是**不覆盖已有配置**：目标文件已存在就先备份成 `.bak-install-<时间戳>`；旧的 `node_modules` 不删，挪成 `node_modules.old-<时间戳>`。
